DroidPier / Samsung DeX alternative for Linux

Independent open-source project

A Samsung DeX style workspace for Linux

DroidPier brings supported Android apps into separate Linux desktop windows while the connected phone continues to run them.

CLEAR DISTINCTION DroidPier is not Samsung DeX

It is an independent Apache-2.0 project. It does not install, unlock, emulate, or redistribute Samsung DeX.

01 / Short answer

Can DroidPier serve as a Samsung DeX alternative on Linux?

It can provide a similar multi-window Android workspace idea for some Linux users, but it uses a different connection and rendering architecture and has different compatibility limits.

DroidPier is aimed at people who want to open apps from a connected Android phone beside their normal Linux applications. It supplies a desktop shell with an app drawer, taskbar, individual app windows, connection controls, and optional phone integration.

It does not activate a hidden manufacturer mode or turn the phone itself into a complete desktop. The Linux computer remains the host workspace, and the phone remains the Android execution device.

02 / Similar goals

The familiar parts of the desktop experience

  • An app drawer for applications discovered on the connected Android phone.
  • Separate windows that can be moved, resized, minimized, maximized, and closed.
  • Keyboard and pointer input sent to the Android application.
  • A desktop taskbar, notification surface, device status, and basic phone controls.
  • USB and Android wireless-debugging connection options.

Those interface ideas make DroidPier relevant when someone wants a DeX style workflow but uses Linux as the computer operating system.

03 / Differences

How DroidPier differs from a manufacturer desktop mode

DroidPier uses Android Debug Bridge, a companion service, a shell agent, virtual displays, and scrcpy-based video transport. The desktop program manages those pieces and presents the result as a Linux workspace.

DroidPier currently does not forward Android audio to the Linux computer. Some apps block secondary displays, capture, DRM content, or input injection. Performance depends on both devices and the connection.

04 / Devices

Does it work with every Android phone?

No universal support claim is possible. The companion can install on Android 8 and newer, but the full desktop workflow depends on Android version, manufacturer changes, secondary-display behavior, app restrictions, encoder support, and permissions.

DroidPier is not limited to Samsung phones by its product design. That does not mean every non-Samsung device will behave identically. The beta currently advertises only combinations that have been validated, with unsupported and untested configurations identified clearly.

05 / Decision

DroidPier may fit when Linux is already your desktop

Consider DroidPier if you want Android apps from your phone beside Linux applications, prefer an open-source tool, can enable USB or wireless debugging, and accept beta limitations. Use your phone manufacturer’s supported desktop mode when you need its official hardware integration and guarantees.

If you only want one mirrored phone screen with extensive mirroring controls, the official scrcpy project may be a more direct choice. DroidPier focuses on the guided workspace and separate-app window model.
