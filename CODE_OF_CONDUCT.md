# Community conduct

Treat everyone with respect. Welcome people of all backgrounds and experience
levels. Discuss ideas and code constructively; give clear, actionable feedback.

Harassment, threats, discriminatory language, sexualized behavior, publication
of private information, and sustained disruption are not acceptable in project
spaces, issues, pull requests, or discussions.

Maintainers may edit or remove inappropriate content, lock discussions, and
restrict participation. Responses should be proportionate to the behavior and
protect affected people. Report concerns privately to the repository maintainer
through an available private contact on their GitHub profile; do not publish
sensitive incident details. If no private contact is available, use GitHub's
platform reporting tools rather than a public project issue.

Maintainer: https://github.com/gysosin
