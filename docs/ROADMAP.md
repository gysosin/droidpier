# Roadmap

## First Linux/Android beta

- Public source and licensing audit.
- Companion setup, release signing and explicit disconnect.
- DEB, Fedora RPM, AppImage and portable Linux archive.
- Fresh-install, upgrade, device and packaging validation.

## Following betas

- Native Windows/macOS frame bridges and real-device validation.
- Windows installer/ZIP and Apple Silicon/Intel DMGs.
- Broader documented device and Linux compatibility.
- Trusted desktop signing when credentials are available.

## Later proposals

Desktop audio forwarding, Linux/Windows ARM, Flatpak/Snap, store listings,
Homebrew/Winget and hosted package repositories are not promised release dates.
Propose substantial changes in an issue before implementation.
