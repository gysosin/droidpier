# DroidPier 0.1.0-beta.1

Your Android. A bigger workspace.

This is an experimental Linux/Android beta candidate, not a stable release.
Physical-device workflows and the full desktop/distribution matrix are still
unverified. The candidate remains a draft under the current release policy.

## Included

Linux desktop packages and the identically signed DroidPier Companion APK.
No development SDK is required for published packages.

## Installation

Choose DEB for Ubuntu/Debian, RPM for Fedora, or AppImage/archive for other
compatible Linux desktops. Package format availability does not establish
distribution support. Follow the repository's user guide. Verify
SHA256SUMS before installation. The desktop installs its bundled companion.

## Known limitations

Windows/macOS are in development and have no downloads in this release. Computer
speaker audio forwarding is unavailable. Some Android applications do not support
secondary displays or capture. Compatibility and frame rate vary by device.
Existing debug-signed companions cannot be upgraded with the release key; the
user must explicitly remove the development companion and regrant permissions.

## Validation

- Passed: fresh-checkout CI, Dart/Flutter/Android analysis and tests, signed APK
  verification, source/privacy checks, dependency-source and license review.
- Passed on Android 15 emulator: setup screen, permission denial, authenticated
  connection, explicit disconnect without immediate reconnection, release-key
  upgrade, and rejection of an incompatible debug signature.
- Smoke-tested in containers: package install, non-root launch under Xvfb, and
  uninstall on Ubuntu 22.04/24.04 and Debian 12/13. Fedora 44 base repositories
  were also smoke-tested. These are not full desktop or real-device tests.
- Still pending: physical USB/Wi-Fi, app windows and input with a real phone,
  clipboard/notification integration, device-removal cleanup, full upgrade
  testing, Mint, current Fedora updates, Arch and openSUSE desktop coverage.

Android 8 is the APK installation minimum, not a promise of full desktop support.
There is no silent automatic updater. Keep a backup of important phone data and
report issues with synthetic examples and no device identifiers.

See the [release validation record](https://github.com/gysosin/droidpier/blob/main/release/acceptance.json)
and [runtime provenance](https://github.com/gysosin/droidpier/blob/main/docs/RUNTIME_PROVENANCE.md).
Each download has an entry in `SHA256SUMS`; dependency sources and both component
and file inventories accompany the installers.
