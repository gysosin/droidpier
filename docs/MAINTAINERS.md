# Maintainers

[gysosin](https://github.com/gysosin) administers the repository, reviews releases
and holds the official Android signing identity. Contributions are welcome through
pull requests; see [contributing](../CONTRIBUTING.md).

Use GitHub issues for reproducible bugs and discussions for usage questions or
ideas. Use [private vulnerability reporting](../SECURITY.md) for security issues.
Do not post personal device identifiers or private logs. No response-time or
support guarantee is implied by this volunteer project.

Original contributors retain their copyright and license rights. Maintainers
must preserve required third-party notices and cannot grant rights they do not own.
